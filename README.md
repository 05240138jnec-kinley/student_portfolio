# Kinley Tshering - Personal Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript for my Diploma in Computer Systems and Networking at Jigme Namgyel Engineering College.

## Live Website
https://05240138jnec-kinley.github.io/student_portfolio/

## Sections
Home, About Me, Skills, Projects, Education and Contact.

## Features
- Dark and light mode toggle
- Mobile-friendly navigation menu
- Typing animation, scroll animations and animated stats
- Project filter buttons
- Interactive network diagram
- Contact form with validation
- Copy-to-clipboard buttons
- Background music button

## Technologies
HTML, CSS, JavaScript

## Project Structure
- `index.html` - page content
- `style.css` - design and responsive layout
- `script.js` - interactive features
- `images/` - profile photo
- `music/` - background music
